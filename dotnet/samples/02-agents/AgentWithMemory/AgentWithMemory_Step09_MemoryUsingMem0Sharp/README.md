# Agent with Memory Using Mem0Sharp

Mem0Sharp is an independent long-term memory library for .NET applications and agents. Its repository contains a Microsoft Agent Framework sample that demonstrates cross-session memory with an in-memory store.

In addition to in-memory storage, Mem0Sharp supports PostgreSQL with pgvector, SQLite, Qdrant, and custom storage providers.

See the [Microsoft Agent Framework memory sample in the Mem0Sharp repository](https://github.com/jihadkhawaja/mem0sharp/blob/main/samples/AgentFrameworkMemory/README.md) for prerequisites, configuration, and run instructions.
